# 陸期×台股 產業多空儀表板

以大陸商品期貨（上期所含 INE、大商所、鄭商所）與前一晚的美國期貨，透過「商品 → 三竹類股」的**實測關聯**，
每天告訴你：哪些台股類股今天的訊號比平常明顯偏多或偏空。

設計原則：**只呈現有證據支持的東西**。關聯要通過歷史檢驗才計分；新的計分方式要在三個不同的訓練／測試切點都過關才採用；
上線後每個區塊都有實盤停損，表現不好會自動降級。

## 兩個版本

| 版本 | 時間（台北） | 用途 |
|---|---|---|
| **今日盤前** | 週一～五 06:17（07:07 補跑） | 開盤前可用：陸期夜盤＋前一晚已收盤的美國期貨 → 看今天 |
| **今日回顧** | 週一～五 17:10 | 收盤後對照：陸期日盤收盤 vs 台股類股實際表現；對明天只看預測卡 |

首頁內容：

- **類股狀態燈**：只有通過實測檢驗的類股才有燈（目前 7 個）。訊號強度 = 今天的分數 ÷ 該類股自己歷史分數的常見幅度，
  達 1 倍以上才亮（偏多／偏空），2 倍以上標「強」。沒亮代表今天在平常的波動範圍內。每張卡片附這個類股自己的樣本外亮燈紀錄。
- **預測卡**：只對有預測關係的族群。國際油價 → 油電燃氣（盤前版）、銅鋁 → 電器電纜（收盤版看明天、盤前版看今天），
  依訊號強度分弱／中／強，並顯示同強度的歷史命中率。
- **最敏感個股**：類股內依個股對陸期的實測連動強度排序。
- **實盤停損提示**：每個區塊顯示實盤累積次數與命中率。

## 計分

- 商品訊號 = 今日漲跌 ÷ 近 20 個交易日波動度（z 分數，穩健估計），2σ 為滿格 ±1；觸及漲跌停再 ×1.5
- 類股分數 = Σ(權重 × 商品訊號) ÷ √Σ|權重| × 100
- 只計「有效」（同日顯著、前後期間方向一致、方向符合產業邏輯）且通過多重比較校正（Benjamini-Hochberg，q = 0.05）的關聯；
  「方向相反」「只有隔日顯著」「數據新增」都不計分
- 沒有實測支持的商品只留報價（頁面收在「未驗證」）：不抓日K、不算價差、不抓國際行情

## 每週校準（`pipeline/calibrate.py`，週六 10:20）

近 2 年陸期主力日報酬（含換月修正）× 證交所類股指數的 β 調整超額報酬：

1. 檢驗每組「商品 → 類股」的同日／隔日相關，決定計分關聯與權重；另做多重比較校正與近 120 日衰退檢查
2. 狀態燈的幅度與樣本外表現（訓練期定權重與幅度、只看測試期），盤前版與收盤版分開算
3. 預測卡的歷史命中率（全期、樣本外、各強度區間）、受惠個股的實測
4. **穩健性檢查**：換 3 個訓練／測試切點（50%／60%／70%），下列做法都要每個切點過關才採用，結果寫在 `calibration.json`：
   狀態燈（亮燈日優於未亮日）、近期轉弱關聯降權、類股迴歸式、盤前只用國際隔夜、共振標記
5. **盤前版亮燈範圍**（用實際的陸期夜盤資料，切點 60%／70%／80%）：只靠陸期夜盤的類股合計看不到預測力（t < 2），
   而有國際對應（商品或同業股票，候選清單在 `mapping.py` 的 `INTL`）的類股**逐一檢查**，自己只用國際隔夜在三個切點都 t ≥ 2
   才在盤前亮燈；其餘類股標示「盤前不亮燈」。逐一檢查是因為合在一起算會被最強的類股帶過關。
   之後證據改變會自動調整。結果在 `calibration.json` 的 `premarket_scope`
6. **開盤後還剩多少**（用累積的類股盤中指數）：盤前訊號的命中率是用「昨收 → 今收」算的，包含開盤跳空。
   校準把當天報酬拆成「昨收 → 進場時間」與「進場時間 → 收盤」（09:05／09:10／09:15／09:30／10:00），頁面列出各進場時間還剩多少。盤前亮燈類股的分數用「只用國際隔夜」
   還是「國際＋陸期夜盤」，也由這項決定：三個切點都是前者的亮燈日在 09:30 之後仍顯著（t ≥ 2）且優於後者，才用前者
7. **預測卡的開盤後檢驗**：預測卡的訊號出來時台股還沒開盤（陸期隔日卡更是前一天收盤後才有），最快開盤才能進場。
   每個預測關係另算「09:05 進場到收盤」與對應個股「開盤買到收盤」的實測；有效商品沒有一個過關（t ≥ 2）時，
   卡片標示「開盤後未過關」並淡化。盤前亮燈類股另列類股內個股在亮燈日的實測（`calibration.json` 的 `basket`）

離線重算（不連網，用上次保存的輸入）：`python pipeline/calibrate.py --offline --out /tmp/cal/calibration.json`

輸出：`docs/data/calibration.json`（網頁與每日計分用）、`calibration_detail.json`（完整換月與日K紀錄，不放上網站）。

## 實盤紀錄與停損（`pipeline/track.py`）

每次訊號記入帳本 `docs/data/track/signals.json`：狀態燈、預測卡方向（以及已停用的舊排法「多空前 3 名」，保留作對照）。
以類股指數的 β 調整超額報酬開獎，彙整在 `docs/data/track.json`。

**停損規則**：每個區塊（盤前狀態燈、收盤狀態燈隔日、陸期預測卡、國際預測卡）累積滿 40 次後，
最近 60 次的方向命中低於 45% 且平均報酬為負 → 頁面把該區塊標為「研究中」並淡化；之後回升自動恢復。
盤前版 09:00 後、收盤版 15:00 前才產生的訊號視為延遲，不計入。

## 盤中與夜盤資料蒐集（`pipeline/intraday.py`，只累積、目前不計分）

證據最強的是同日關係，但收盤版 17:10 才出來。陸期日盤和台股同時交易，如果陸期早盤能領先台股午盤，才是當天可用的訊號；
盤前版實際用的是夜盤，但回測只能拿前一天日盤代替。這兩件事都要先有盤中資料才能驗證，所以每天收盤版順便累積：

- 陸期 30／60 分鐘線（含夜盤）、台股類股指數每 30 分鐘的值（證交所每 5 秒指數統計，可回補歷史）
- 每天盤前版實際用的夜盤漲跌
- 存在 `pipeline/cache/intraday/`；手動多補一些歷史：Actions → **Intraday backfill**
- 累積滿 40 天後，每週校準會做初步檢驗（到 10:30／12:00 的陸期走勢 → 之後到台股收盤；夜盤 → 台股當天），結果在 `calibration.json` 的 `intraday`

## 資料來源

- 陸期：新浪財經期貨行情（連續主力），漲跌以昨結算為基準；日K與個別合約（換月修正）
- 國際：Yahoo 期貨日線（只抓有實測支持的：油品、COMEX 鋁）
- 台股：證交所／櫃買中心收盤、產業別、類股指數、休市日曆
- 漲跌停幅度：上期所、能源中心、鄭商所每日公告（大商所、廣期所用預設值）

每次執行寫出 `docs/data/status.json`，頁面「資料來源狀態」逐一列出各來源是否正常。

## 部署與維運

1. 推上 `main`；Settings → Pages → Source 選 **GitHub Actions**
2. Cloudflare Worker：貼上 `worker/trigger-worker.js`，設定 Secret `GH_TOKEN`（fine-grained，只選本 repo、Actions: Read and write）
   與 `ADMIN_KEY`（管理密碼，至少 20 字元）；Worker 網址填進 `docs/config.js`
3. Actions → **Daily update** → Run workflow 跑第一次

- **排程**：Cloudflare Worker 定時觸發為主（06:17、07:07、17:10、週六校準、每 4 小時停擺監控）。GitHub 自己的排程常延遲數小時，
  盤前版與收盤版各只留一條備援；今天已有準時版本或已過時段就略過，略過時**不存檔、不部署**
- **資料分支**：每日與每週產生的資料存在 `data` 分支，`main` 只放程式碼。`deploy.yml` 把兩者組合後部署；
  部署步驟失敗會自動重試一次。本機看真實資料：`python pipeline/datastore.py restore`
- **失敗通知**（`notify.yml`）：流程失敗自動開 GitHub Issue，成功後自動關閉。只有「發佈網站」失敗（資料已更新）會另外標示，
  不會誤報成資料更新失敗；核心資料來源抓取失敗另開「資料來源異常」
- **停擺監控**（`watchdog.yml`）：超過 30 小時沒有成功更新且錯過交易日排程 → 開 Issue；也在 `GH_TOKEN` 到期前 30 天提醒
  （到期日記在 `.github/token-expiry.txt`，更換後記得更新）
- **CI**（`ci.yml`）：workflow 語法、單元測試、電腦版與手機版頁面檢查（破版、文字截斷、狀態燈與預測卡數量、PWA），
  分別用真實資料與離線假資料
- **管理者**：訪客看不到「立即更新」；擁有者在頁尾（手機版在「更多」）輸入管理密碼後才出現，密碼只存在該裝置

## 試過但沒有採用的做法

留著紀錄，避免重複嘗試；每週校準仍會重測，結果在頁面「研究與驗證 → 計分方式的回測比較」：

| 做法 | 結果 |
|---|---|
| 多空前 3 名排名 | 每天能算分的類股只有 9～10 個，同幾個類股幾乎每天上榜，已改為狀態燈 |
| 5 日／20 日動能 | 隔日預測力沒有改善，已刪除 |
| 依類股可信度調整分數 | 改為只計有效關聯後已無差異，已刪除 |
| 弱訊號日提醒 | 由狀態燈取代（沒亮就是弱），已刪除 |
| 法人買賣超、量比、融資券 | 沒有歷史資料可以驗證是否有用，已刪除 |
| 當日漲跌前 5 強／弱 | 與陸期無關，已刪除 |
| 共振標記 | 三個切點沒有都過關，頁面不顯示 |
| 類股迴歸式（處理高度相關的商品） | 同日或隔日各有輸贏，三個切點沒有都過關 |
| 近期轉弱關聯降權、盤前只用國際隔夜 | 三個切點沒有都過關 |

本頁為量化研究參考，不構成投資建議。
